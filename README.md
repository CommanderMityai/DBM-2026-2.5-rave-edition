# Че это
Если вы как-то сюда попали, то это вам не надо. Данный репозиторий - аддон для аддона для варкрафта, содержащий мемную и смешную пацанскую музяку сообщества "Казимир".

# А зачем мне это
Чтобы ваши уши ласкали такие звуки как ПОЧЕМУ Я БЛЯДЬ или же "момент-братан+30db_bassboosted_dolbitnormalno.mp3". Чтобы рейды и данжи не были скучными. Чтобы мозг плавился на очередном пуле. Придумайте сами

# Ладно, как установить?
Просто скачать зипник, распаковать в папку Interface\AddOns игры. Сделать /reload или полностью перезайти. Желательно еще всякие другие саундпаки подчистить нахуй чтобы они не загружали выборку рандома.

В зипнике есть модуль Sounds.lua, чистящий Sounds.lua по адресу DBM-Core/modules, он удаляет дефолтные звуки игры из пула.

# В чем отличие от версии, которую ты писал в 2021 году?
Почистил от говна насколько это можно в рамках опыта, который я получил. Ключевые изменения:
- За основу взят другой метод вставки музыки и аудиофайлов. Создание локальных table, которые модально вставляются в DBM. Поддержка только .mp3 (Хоть и две строчки поменять чтобы была поддержка .ogg - впадлу).
- Другой метод вставки аудиофайлов для алертов, пулов и таймеров. Добавлена библиотека sharedmedia через которую осуществляется вставка в эти функции.
- Рефакторинг кода вставки, при котором теперь можно спокойно обновлять DBM-Core (Ничего не вырезано и не перекодировано!)
- Поддержка добавления новых файлов. Старые методы были захардкожены.
- ХЗ слова умные короче

# А как мне свою смешную хуйню вставить?
Для звуков на алерты/пулы/таймер - Открыть библиотеку sharedmedia, открыть sharedmedia.lua, найти 57 строчку и увидеть как прописывается новые звуки. Сами новые звуки вставлять по пути SharedMedia/Sound/...  .mp3 или OGG.

Для звуков на музыку в бою, звуков при победе над боссом, звуков при вайпе - Открыть musicloadlist.lua в папке DBM-CommanderMityaisMusicPack, и для звуков музыки - добавлять по шаблону в table musicTable, для звуков победы table victoryTtable, для звуков вайпа - вы угадали, table defeatTable. Поддержка только .mp3
